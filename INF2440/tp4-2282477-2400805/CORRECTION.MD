# Correction

Vous serez corrigés sur le respect des exigences fonctionnelles de l’énoncé ainsi que la qualité du JavaScript.

Important :
- Lisez **attentivement** l'énoncé, le code fourni et les commentaires dans le code.
- Utilisez les outils de développement de votre navigateur web pour vous aider à déboguer votre code JS (raccourci <kbd>F12</kbd>).
- Utilisez les méthodes des tableaux JS (`map`, `filter`, `find`, `reduce`, etc.) au lieu des boucles `for` classiques.
- N'ajoutez pas de fichiers non-voulu à l'entrepôt Git, incluant des fichiers dans `server/data/`. (Vous pouvez supprimer les fichiers de bases de `server/data/`, tant que cela ne créé pas de bogue dans votre code).
- Il peut y avoir plusieurs manières correctes de résoudre un problème. Si vous avez une solution différente de celle attendue, mais qui fonctionne, elle sera considérée comme correcte.
- Des points peuvent être retirés pour une mauvaise utilisation du langage JS. Par exemple : l'utilisation de `var` au lieu de `let` ou `const`.
- L'ensemble des tests fournis doivent réussir lors de votre remise.
- Aucune erreur ne doit être détectée lors de l'exécution de la commande `npm run lint`, aussi bien dans le dossier `site` que dans le dossier `server`.
